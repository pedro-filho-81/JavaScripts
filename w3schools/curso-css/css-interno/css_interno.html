CSS interno

Uma folha de estilo interna pode ser usada se uma única página HTML tiver um estilo único.

Exemplo

Os estilos internos são definidos dentro do elemento <style>, na seção <head> de uma página HTML. 

<style>
    /* fundo azul */
    body {
        /* fundo do corpo na cor azul */
        background-color: lightblue;
    }

    h1,
    h2 {
        color: navy;
        margin-left: 20px;
    }

    p {
        color: darkred;
        font-size: 25px;
        margin: 20px;
        text-align: justify;
    }

    span {
        font-size: 30px;
        font-weight: bold;
    }
</style>
