O atributo Name para <input>

Observe que cada campo de entrada deve ter um atributo name para ser submetido.

Se o atributo name for omitido, o valor do campo de entrada não será enviado. 

    <form action="#">
      <label for="fname">Primeiro Nome:</label>
      <input type="text" id="fname" name="fname" value="João" />
      <input type="submit" name="fname2" value="Enviar" />
    </form>
