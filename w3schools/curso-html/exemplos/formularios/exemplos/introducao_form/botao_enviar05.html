O Botão Enviar

Define <input type="submit" /> um botão para enviar os dados do formulário a um manipulador de formulário.

O manipulador de formulários é normalmente um arquivo no servidor com um script para processar os dados de entrada.

O manipulador de formulário é especificado no atributo action do formulário. 

    <form action="/action.php">
      <label for="fname">Primeiro nome:</label>
      <input type="text" id="fname" name="fname" value="João" />
      <label for="lname">Último nome:</label>
      <input type="text" id="lname" name="lname" value="Douglas" />
      <input type="submit" value="Enviar" />
    </form>
